📦 Inventory Dashboard

A modern Inventory Management Dashboard built to simplify stock tracking, product management, and operational visibility. This application provides a clean UI and efficient workflows for managing inventory in real time.

🚀 Features
📊 Dashboard Overview
View total inventory, stock levels, and key metrics at a glance
➕ Add Products
Add new items with details like name, quantity, and category
✏️ Edit & Update
Modify product information dynamically
❌ Delete Items
Remove inventory records easily
🔍 Search & Filter
Quickly find products using search and category filters
📉 Low Stock Tracking
Identify items that need restocking
⚡ Fast & Responsive UI
Optimized for smooth performance

These features align with modern lightweight inventory tools that focus on simple workflows like adding, editing, and tracking stock efficiently .
