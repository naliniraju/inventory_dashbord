# AI HR Recruiter Playbook

A responsive React + Tailwind CSS tutorial platform for modern HR professionals and AI recruiting teams. It delivers an in-depth, expert-style learning path for AI hiring strategy, ATS workflows, sourcing automation, screening, interview orchestration, and prompt engineering.

## Features

- Expert-led recruitment curriculum with modular lessons
- AI prompt engineering examples for HR workflows
- ATS stage design, candidate experience, and screening strategy
- Practical workshop checklist for building a live hiring process
- Fully responsive UI for mobile, tablet, and desktop

## Tech stack

- React
- Vite
- Tailwind CSS

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the URL shown in the terminal.

## Build

```bash
npm run build
```
